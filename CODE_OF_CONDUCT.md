# Code of conduct

This project follows the principles of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
This summary references that text rather than reproducing it.

Be respectful, inclusive and constructive. Accept good-faith feedback, respect
privacy and focus on improving the project. Harassment, discrimination, threats,
sexualized conduct and publishing private information are unacceptable in project
spaces and when representing the project.

Maintainers may remove harmful content and apply proportionate restrictions,
including temporary or permanent participation limits. Reports should be handled
privately and fairly, with protection against retaliation. To report misconduct
privately, use the repository's **Security** tab (**Report a vulnerability**) and
mark the report as a conduct issue. Do not publish personal details in a public issue.
